온보딩 → 데일리 설문 → 미션 생성으로 이어지는 규칙 전체를 정리한 문서입니다.

`src/lib/survey-scoring.ts`, `src/lib/classifier.ts`, `src/pages/onboarding.tsx`,

> 공통 원칙: 고립/은둔/환자 같은 규정 언어와 난이도 숫자, 점수·컷오프는 사용자에게 절대
> 노출하지 않는다. 연속(스트릭) 프레이밍 금지, 실패에 대한 처벌 없음, 무비용(결제·구매 미션 금지).

## 1. 온보딩 (최초 1회) — 설문 JSON 기반

문항·선택지·척도·역코딩·분기·채점 파라미터는 전부 `src/data/onboarding-survey.json`(v1.2)에서
읽는다(코드에 하드코딩하지 않음). 출처: 은둔 체크리스트(김혜원·김지연 2022 등),
사회적 고립 척도(조미형 외 2022).

### 1-1. 첫 실행 설문 17문항
말풍선 UI로 한 번에 하나씩. 진행 표시는 숫자 없이 부드러운 게이지만.

- **은둔 체크리스트 2문항** (`sc_q1` 외출 정도 1~8, `sc_q2` 주된 이유 1~6)
- **은둔 상황 체크리스트 15문항** (`ss1~ss15`, 응답 0~3: 전혀 아니야~완전 그래)

이후 닉네임·캐릭터 색을 정하면 온보딩 완료 → 데일리 체크인으로.

### 1-2. 첫 실행 채점 (`scoreFirstLaunch` — 전부 내부 상태, 화면 비노출)
- **은둔 판정**: sc_q1 ∈ {1..4} AND sc_q2 ∉ {4(질병),5(임신·출산)} → 은둔=true.
- **외출부담**: sc_q1 1~2=상 / 3~4=중 / 5~8=하.
- **심각도**: Σ(ss1..ss15) 0~45 → 0~10 낮음 / 11~25 중간 / 26~45 높음.
- **초기 난이도 밴드**: 은둔=L1, 아니면 낮음→L3~4 / 중간→L2 / 높음→L1.
- **영역 시드**: 문항별 (응답값 × areas 가중치)를 영역별 누적(생활리듬·자기돌봄_신체·관계·
  사회진입·정서·은둔심각도). 라우팅용 휴리스틱.
- **임시 단계**: 은둔=true → 은둔(우선). 아니면 심각도 밴드로 높음→고도고립 / 중간→고립위험군 /
  낮음→비위험군. '나 알아가기' 완료 시 확정 단계로 대체된다.
- **금지조건**: 단계 기본값(아래 표) + 외출부담 상이면 외출·대면 추가, 중이면 외출 추가.
  은둔심각도 시드가 높으면(≥6) 관계·사회진입 게이트 잠금(관계대면·외출 추가).

| 단계(내부 코드) | 기본 난이도 밴드 | 기본 금지조건 |
|---|---|---|
| 은둔 (secluded) | L1 | 외출, 대면, 전화, 관계대면 |
| 고도고립 (highly_isolated) | L1~2 | 대면, 전화, 외출 |
| 고립위험군 (at_risk) | L2~3 | 대면은 저강도만 |
| 비위험군 (not_at_risk) | L3~4 | 없음 |

- 미션 생성 API 호환을 위해 sleep/outing/contact/area 맥락값을 응답에서 파생해 전달한다
  (`deriveLegacyAnswers`, 프롬프트 맥락 전용).

### 1-3. '나 알아가기' — 고립 척도 25문항, 5챕터 데일리 카드
- 홈에 오늘의 챌린지 카드와 동일한 형태의 "나 알아가기 · 오늘 한 챕터 (30초)" 카드가
  하루 1장 노출된다(오늘 챕터를 진행했으면 숨김, 5챕터 완료 후엔 더 이상 노출 안 함).
- 챕터: ch1 요즘의 나(k1~k7) / ch2 가족·친척(k8~k12) / ch3 친구·지인(k13~k18) /
  ch4 일하는 곳(k19~k22) / ch5 기댈 곳(k23~k25).
- **분기**: ch2 시작 시 "가족·친척 있어?" 아니오→챕터 건너뜀, ch4 "일해본 적 있어?"
  아니오→건너뜀. 건너뛴 챕터는 미응답으로 기록.
- 챕터는 건너뛰기 가능("오늘은 여기까지"), 중단 지점 저장 후 다음날 이어하기.
- **채점(5챕터 완료 시, `scoreKnowYourself`)**: 역코딩(reverse_items는 최대값−응답) 적용
  총점 → 응답 문항 기준 100점 만점 비례 환산 → 컷오프 0~43 비위험군 / 44~59 위험군 /
  60+ 고위험군.
- **단계 확정(`finalStageFrom`)**: 은둔체크 양성=은둔(우선), 60+=고도고립, 44~59=고립위험군,
  0~43=비위험군. 단계가 바뀌면 밴드·금지조건을 확정 단계 기본값으로 재설정하고 오늘 미션
  후보를 새 규칙으로 재생성한다(수락한 미션은 유지).

### 1-3. 단계별 허용 영역 (누적형, 2026-07-15 확정 규칙)
단계가 오를수록 하위 영역 위에 하나씩 쌓인다. **배열의 마지막 = 그 단계의 '타깃 영역'**
(그 단계에서 정복해야 하는 목표 영역).

| 단계 | 허용 영역 | 타깃 영역 |
|---|---|---|
| 은둔 | 생활리듬 | 생활리듬 |
| 고도고립 | 생활리듬, 자기돌봄 | 자기돌봄 |
| 고립위험군 | 생활리듬, 자기돌봄, 관계 | 관계 |
| 비위험군 | 생활리듬, 자기돌봄, 관계, 사회진입 | 사회진입 |

- 영역 게이트(`isAreaEligible`): 사회진입은 '외출' 금지 시 제외, 관계는 '관계대면' 금지 시 제외.
- 타깃 영역이 게이트에 막히면 바로 아래 허용 영역으로 안전하게 내려간다(`getStageTargetArea`).
- 단계 미확정(온보딩 전)이면 가장 안전한 생활리듬만 허용.

## 2. 데일리 설문 (매일, 편지 형태)

질문 3개:

1. **컨디션** — 바닥 / 그저 그럼 / 괜찮음
2. **활동 선택** — "오늘은 어떤 걸 해보고 싶나요?"
   - 시드뱅크의 구체 활동(카테고리)을 보여주되, **타깃 영역 안의 활동만** 노출한다.
   - 각 활동은 카테고리 게이트(금지태그·최소 컨디션)를 통과해야 표시된다.
     예: 외출이 필요한 활동은 '외출' 금지 사용자에게 숨김, 일부 활동은 컨디션 '그저 그럼' 이상 필요.
   - 타깃 영역의 활동이 게이트로 전부 닫히면 바로 아래 허용 영역으로 스텝다운.
   - "잘 모르겠어요" 선택 가능 → 활동 지정 없이 단계 기본 흐름으로 진행.
3. **관심사** — 음악, 동물 등 취향 한 가지 (미션 문구에 반영됨)

선택한 활동의 카테고리 id(`activityId`)는 미션 생성까지 흘러가서, 타깃 영역 미션 중
최소 1개가 그 활동과 자연스럽게 이어지도록 한다.

## 3. 미션 생성 (하루 4개)

### 3-1. 구성 규칙
- **타깃 2개**: 단계의 타깃 영역에서 (난이도를 서로 다르게).
- **랜덤(다양성) 2개**: 허용 영역 중 타깃을 제외한 나머지에서.
  - 후보 영역이 2개 이상이면 서로 다른 두 영역에서 1개씩.
  - 후보가 1개면 그 영역에서 2개.
  - 후보가 없으면(은둔) 4개 모두 타깃 영역에서.

단계별 실제 결과:

| 단계 | 구성 |
|---|---|
| 은둔 | 생활리듬 4개 |
| 고도고립 | 자기돌봄 2 + 생활리듬 2 |
| 고립위험군 | 관계 2 + (생활리듬·자기돌봄에서 1개씩) |
| 비위험군 | 사회진입 2 + (생활리듬·자기돌봄·관계 중 두 영역에서 1개씩) |

### 3-2. 오늘의 난이도 밴드
1. 시작값 = 사용자의 현재 밴드(`currentBandLow~High`).
2. 컨디션이 '바닥'이면 -1 (최소 L1).
3. 영역별 캡(`capBandForArea`): 관계 영역은 은둔이면 L1 고정, 고도고립이면 최대 L2
   (저강도·비대면만).
4. 이틀 연속 건너뛴 다음 날은 타깃 영역을 강제로 생활리듬으로 낮춘다(`forceLowBurdenArea`).

### 3-3. 생성 파이프라인 (서버)
1. **LLM 생성** (5초 타임아웃): 단계·영역·밴드·금지조건·온보딩 답·컨디션·관심사·선택 활동을
   프롬프트로 전달. 시드뱅크의 열린 카테고리와 시드를 few-shot으로 제공(복붙 금지, 변주).
2. **결정적 검증·수리**:
   - 영역이 허용 목록에 없으면 버림, 난이도는 그 영역의 밴드로 클램프.
   - 다양성 영역 편중 방지(후보 2개 이상이면 영역당 1개까지).
   - **한 활동 원칙**: "~하고 ~하기", "~하면서" 등 병렬 활동 감지(`hasParallelActivities`) 시
     검증된 시드로 교체(`repairMission`). 수리 후에도 위반이 남으면 전체 폴백.
   - 제목 중복 제거. 구성(타깃 N + 다양성 M)이 안 채워지면 전체 폴백.
   - **구성 밸런스**(`enforceComposition`): 관심사 반영 2개 + 관심사 없는 일반 미션 1개,
     사진 인증 가능한 미션 1개 이상이 되도록 결정적으로 보정한다.
     (시드뱅크에서 대체 가능한 시드가 있을 때 교체하는 best-effort 방식 — 대체 시드가
     없는 극단 케이스에서는 원문을 유지한다.)
3. **폴백**: LLM 실패·타임아웃·검증 실패 시 시드뱅크에서 같은 구성 규칙으로 결정적 선택
   (`selectDiverseFallbackMissions`). 클라이언트도 서버 자체가 실패하면 로컬 폴백 뱅크 사용.

### 3-4. 카테고리 게이트 (시드뱅크 단일 출처)
- 금지태그: 카테고리에 필요한 행동(외출·대면·전화)이 사용자 금지조건과 겹치면 닫힘.
- 최소 컨디션: 일부 카테고리는 컨디션 '그저 그럼' 이상에서만 열림.
- 밴드 내 후보가 게이트로 전부 막히면 밴드 제약만 완화하고 게이트는 절대 우회하지 않는다.

### 3-5. 미션 문구 규칙
- 아주 작은 행동(프롬프트 목표 5~15분). 실제 소요시간은 난이도별 기본값 2~15분이며,
  LLM이 제시한 값은 최대 30분까지 허용된다. 구체적·실행 가능. 회고 질문 한 줄 포함.
- 지시·명령·평가·비교·재촉 표현 금지("~해야 한다", "꼭", "매일" 등).
- 컨디션 바닥이면 기록형(쓰기·고르기·표시) 위주.

## 4. 다음 날 난이도 조정 (`adjustBandNextDay`)

| 어제 결과 | 부담 응답 | 조정 |
|---|---|---|
| 완료 | 😌 쉬웠어요 | 밴드 +1 (최대 L5) |
| 완료 | 😐 적당했어요 | 유지 |
| 완료 | 😣 버거웠어요 | 밴드 -1 (최소 L1) |
| 미완료 | — | 밴드 -1 |
| 2일 연속 미완료 | — | L1로 리셋 + 위로 메시지, 다음 날 생활리듬부터 재시작 |

실패를 탓하는 문구 없이, 조정 사실은 부드러운 안내 문구로만 전달한다.

## 5. 사진 인증 칭찬

- 완료 후 사진을 올리면 LLM(12초 타임아웃)이 사진에서 보이는 것을 짚어 1~2문장 칭찬 생성.
- 사진이 미션과 무관해 보여도 지적하지 않고 시도 자체를 칭찬(실패 처벌 없음).
- 결정적 가드: 규정 언어(고립·은둔·환자), 난이도 표기(레벨·단계), 연속/스트릭 표현이
  섞이면 즉시 폐기하고 준비된 칭찬 문구로 대체.
- 분석 실패 시에도 완료는 그대로 인정된다.
