> 공통 원칙: 고립/은둔/환자 같은 규정 언어와 난이도 숫자, 점수·컷오프는 사용자에게 절대

## 1. 온보딩 (최초 1회) — 설문 JSON 기반

문항·선택지·척도·역코딩·분기·채점 파라미터는 전부 `src/data/onboarding-survey.json`(v1.5)에서
읽는다(코드에 하드코딩하지 않음). 출처: 은둔 체크리스트(김혜원·김지연 2022 등),
사회적 고립 척도(조미형 외 2022).

### 1-1. 첫 실행 설문 17문항
말풍선 UI로 한 번에 하나씩. 진행 표시는 숫자 없이 부드러운 게이지만.

- **은둔 체크리스트 2문항** (`sc_q1` 외출 정도 1~8, `sc_q2` 주된 이유 1~6)
- **은둔 상황 체크리스트 15문항** (`ss1~ss15`, 응답 0~3: 전혀 아니야~완전 그래)

이후 닉네임·캐릭터 색을 정하면 온보딩 완료 → 데일리 체크인으로.

### 1-2. 첫 실행 채점 (`scoreFirstLaunch` — 전부 내부 상태, 화면 비노출)
- **은둔 판정**: sc_q1 ∈ {1..4} AND sc_q2 ∉ {4(질병),5(임신·출산)} → 은둔=true.
- **외출부담**: sc_q1 1~2=상 / 3~4=중 / 5~8=하.
- **심각도**: Σ(ss1..ss15) 0~45 → 0~10 낮음 / 11~25 중간 / 26~45 높음.
- **초기 난이도 밴드**: 은둔=L1, 아니면 낮음→L3~4 / 중간→L2 / 높음→L1.
- **영역 시드**: 문항별 (응답값 × areas 가중치)를 영역별 누적(생활리듬·자기돌봄_신체·관계·
  사회진입·자기돌봄_정서·은둔신호). 라우팅용 휴리스틱.
- **임시 단계**: 은둔=true → 은둔(우선). 아니면 심각도 밴드로 높음→고도고립 / 중간→고립위험군 /
  낮음→비위험군. '나 알아가기' 완료 시 확정 단계로 대체된다.
- **금지조건**: 단계 기본값(아래 표) + 외출부담 상이면 외출·대면 추가, 중이면 외출 추가.
  은둔신호 시드(ss5·ss6·ss14)가 높으면(≥6) 관계·사회진입 게이트 잠금(관계대면·외출 추가).

| 단계(내부 코드) | 기본 난이도 밴드 | 기본 금지조건 |
|---|---|---|
| 은둔 (secluded) | L1 | 외출, 대면, 전화, 관계대면 |
| 고도고립 (highly_isolated) | L1~2 | 대면, 전화, 외출 |
| 고립위험군 (at_risk) | L2~3 | 대면은 저강도만 |
| 비위험군 (not_at_risk) | L3~4 | 없음 |

- 미션 생성 API 호환을 위해 sleep/outing/contact/area 맥락값을 응답에서 파생해 전달한다
  (`deriveLegacyAnswers`, 프롬프트 맥락 전용).

### 1-3. '나 알아가기' — 고립 척도 25문항, 5챕터 데일리 카드
- 홈에 오늘의 챌린지 카드와 동일한 형태의 "나 알아가기 · 오늘 한 챕터 (30초)" 카드가
  하루 1장 노출된다(오늘 챕터를 진행했으면 숨김, 5챕터 완료 후엔 더 이상 노출 안 함).
- 챕터: ch1 요즘의 나(k1~k7) / ch2 가족·친척(k8~k12) / ch3 친구·지인(k13~k18) /
  ch4 일하는 곳(k19~k22) / ch5 기댈 곳(k23~k25).
- **분기**: ch2 시작 시 "가족·친척 있어?" 아니오→챕터 건너뜀, ch4 "일해본 적 있어?"
  아니오→건너뜀. 건너뛴 챕터는 미응답으로 기록.
- 챕터는 건너뛰기 가능("오늘은 여기까지"), 중단 지점 저장 후 다음날 이어하기.
- **채점(5챕터 완료 시, `scoreKnowYourself`)**: 역코딩(reverse_items는 최대값−응답) 적용
  총점 → 응답 문항 기준 100점 만점 비례 환산 → 컷오프 0~43 비위험군 / 44~59 위험군 /
  60+ 고위험군.
- **챕터별 라우팅(`applyChapterRouting`, v1.5 reflection_timing)**: 챕터를 완료할 때마다
  그 챕터의 하위점수(역코딩 반영 합)를 매핑된 영역 시드에 더해 '영역 우선순위'만 갱신한다
  (ch1→사회진입·자기돌봄_정서, ch2·ch3→관계, ch4·ch5→사회진입). 건너뛴 챕터는 갱신 없음.
  회복단계는 챕터 단위로 바꾸지 않는다 — 44/60 컷오프는 전체 총점 기준이라 부분 점수로
  판정하지 않고, 5챕터 완료 전에는 첫 실행의 임시 단계를 유지한다.
- **단계 확정(`finalStageFrom`)**: 은둔체크 양성=은둔(우선), 60+=고도고립, 44~59=고립위험군,
  0~43=비위험군. 단계가 바뀌면 밴드·금지조건을 확정 단계 기본값으로 재설정하고 오늘 미션
  후보를 새 규칙으로 재생성한다(수락한 미션은 유지).

### 1-3. 단계별 허용 영역 (누적형, 2026-07-15 확정 규칙)
단계가 오를수록 하위 영역 위에 하나씩 쌓인다. **배열의 마지막 = 그 단계의 '타깃 영역'**
(그 단계에서 정복해야 하는 목표 영역).

| 단계 | 허용 영역 | 타깃 영역 |
|---|---|---|
| 은둔 | 생활리듬 | 생활리듬 |
| 고도고립 | 생활리듬, 자기돌봄 | 자기돌봄 |
| 고립위험군 | 생활리듬, 자기돌봄, 관계 | 관계 |
| 비위험군 | 생활리듬, 자기돌봄, 관계, 사회진입 | 사회진입 |

- 영역 게이트(`isAreaEligible`): 사회진입은 '외출' 금지 시 제외, 관계는 '관계대면' 금지 시 제외.
- 타깃 영역이 게이트에 막히면 바로 아래 허용 영역으로 안전하게 내려간다(`getStageTargetArea`).
- 단계 미확정(온보딩 전)이면 가장 안전한 생활리듬만 허용.

## 2. 온보딩 직후: 함께 시작하는 일주일 (BA v2, `src/lib/ba.ts` · `src/pages/onboarding-week.tsx`)

설문 완료 시 심리교육 카드 없이 곧바로 1주 고정 미션 주간으로 진입한다(2026-07-24 결정).

- Day1~7 고정 초소형 미션(`ONBOARDING_WEEK`, 실패가 거의 불가능한 1~4분 미션).
  Day6 외출 미션은 '외출' 금지 사용자에게 실내 대체 문구로 치환.
- 매일: 기분 5단계 탭 → 미션 카드(했어요/건너뛰기) → 완료 시 P(즐거움)·M(뿌듯함) 3단 탭.
- 계획 입력 없음. 명시적 skip만 기록.
- 7일 후 관심사 다중 선택(건너뛰기 가능) → `summarizeOnboardingWeek`:
  - **mood_baseline**: 7일 기분 평균(마이페이지 그래프 기준선).
  - **pm_pattern**: 완료 미션의 영역별 P/M 초기 누적(`areaPM`).
  - **skip_pattern**: 명시적 skip ≥2회면 본 사이클 1주차부터 회피 슬롯 조기 활성화.
- `phase='cycle'`, `cycleStartDay` 기록 후 본 사이클로.

## 3. 본 사이클 — 데일리 설문 · 슬롯 제안 (BA v2)

### 3-1. 데일리 설문 2문항 (`daily-checkin.tsx`)
1. **기분** — 5단계 탭(1~5). 내부에서만 사용, 숫자 비노출.
2. **활동 선택** — 타깃 영역 안의 열린 카테고리만 노출(게이트: 금지태그·최소컨디션).
   기분→컨디션 브리지(`moodToCondition`): ≤2=바닥, 3=그저 그럼, ≥4=괜찮음.
- 관심사는 매일 묻지 않는다 → **주 1회 갱신 카드**(건너뛰기 가능, 선택 시 3일 부스트).
- **4주마다 게이트 재확인 1문항**이 설문 앞에 끼어든다: "요즘 ~는 어때요?" —
  "괜찮아졌어요"일 때만 해당 금지 플래그 해제(단계·밴드 불변). 게이트를 먼저 완화하는
  일은 절대 없다.

### 3-2. 오늘의 슬롯 (`planTodaySlots`, 로컬 시드뱅크 · LLM 미사용)
본 사이클 1주차 = 3슬롯(타깃 2 + 즐거움 1), 2주차부터 회피 1 추가(온보딩 skip_pattern으로
조기 활성화 가능).

| 슬롯 | 선택 규칙 | 배지 문구 |
|---|---|---|
| 타깃 ×2 | 설문 선택 활동(카테고리) 우선, 단계 타깃 영역·밴드·게이트 준수 | "내가 고른 영역" |
| 즐거움 ×1 | 영역별 P 누적 평균 상위(허용∩게이트) 영역, 데이터 없으면 타깃 영역에서 취향 변주. 밴드 하단 사용 | "최근 즐거움이 컸던 쪽이에요" |
| 회피 ×1 | 2주 창에서 같은 영역 명시적 skip ≥2회인 대상 → 한 단계 낮은 밴드의 더 작은 미션 | "계속 미뤄왔던 조각, 더 작게 쪼갰어요" |

skip 데이터가 없으면 회피 슬롯 대신 타깃 다양성 미션 1개로 대체(좋은 신호).

### 3-3. 난이도 = B안 계획 우선형 (`effectiveLevel`)
- 슬롯마다 토글 **가볍게(-1) / 보통(0) / 도전(+1)**. 최종 난이도 = clamp(밴드 + 토글, 영역캡).
- 기분은 난이도 계산에 개입하지 않는다. 기분 ≤2인 날은 토글 **기본값만** '가볍게'로 추천
  (`defaultToggle`). 넛지 상태(`nudgeDefaultNormal`)면 기본 '보통'.
- 계획 입력: 시간대(아침/점심/저녁) 공통, 고립위험군+ "어디서", 비위험군+ "누구와"(`planDepth`).
- 건너뛰기 = 발목 사유 탭(`SKIP_REASONS`) → skip 원장(`skipLog`)에 기록(회피 슬롯 재료).

### 3-4. 사후 평정 (`reflection.tsx`)
- 부담 이모지 폐지 → **P(즐거움)·M(뿌듯함) 0–10 슬라이더 2개**(완료 시에만).
- 초기값 없음(미조작 시 내부 3 저장 — 중앙값 편향 방지). 내부 5구간 환산(`pmTo5`).
- 마이크로 피드백 한 줄(`microFeedback`): 최근 7일 완료일 ≥3 AND 미완료일 ≥2 AND
  완료일 기분이 실제로 높을 때만 "조각을 맞춘 날 기분이 평균 N칸 높았어요."

## 4. 다음 날 조정 · 진급 (BA v2)

### 4-1. 밴드 조정 (`adjustBandNextDayV2`, day_result 3분기)
M_band = 완료 타깃 슬롯 M 평균(5구간), T = 그날 최고 토글.

| day_result | 조건 | 조정 |
|---|---|---|
| completed(타깃 완료) | M≥4 & T=도전 | 밴드 +1 |
| completed | M≥4 & T=보통/가볍게 ×2일 연속 | 토글 기본값 '보통' + 밴드 +1 (넛지) |
| completed | M≤2 | 밴드 유지 + 위로 문구, ×2일 연속이면 기본값 '가볍게' 복귀 |
| completed | M≤2 & P_day≤2 | + 즐거움 슬롯 가중치↑(해당 영역 부스트) |
| kept(즐거움·회피만 완료) | — | 유지, 미완료 카운터 리셋 |
| missed(아무것도 없음) | 1일 | 밴드 -1 |
| missed | 2일 연속 | L1 리셋 + 위로 문구 |

**완료한 날은 어떤 형태든 하향 없음.**

### 4-2. 진급 (주 1회 배치, `checkPromotion`)
전부 AND: ① 최근 2주 완료율 ≥60%(분모=타깃+즐거움 제안 수, 회피 완료는 보너스)
② 2주 창 타깃 완료 ≥3회 ③ M 추세 비하락(첫 평가는 면제).
- 통과 시 홈에 동의 카드 "다음 조각으로 넘어가볼까요?" — 동의해야 단계 상승.
  거절 시 2주간 재제안 없음. **강등 없음**, 금지 게이트는 진급과 무관하게 유지.

### 4-3. 마이페이지 (`StatsSection`)
- 기분 곡선(최근 14일) × 완료 표시 오버레이 + 온보딩 기분 기준선(점선).
- 영역별 P/M 평균 바("나에게 잘 맞았던 것들").

## 5. 사진 인증 칭찬

- 완료 후 사진을 올리면 LLM(12초 타임아웃)이 사진에서 보이는 것을 짚어 1~2문장 칭찬 생성.
- 사진이 미션과 무관해 보여도 지적하지 않고 시도 자체를 칭찬(실패 처벌 없음).
- 결정적 가드: 규정 언어(고립·은둔·환자), 난이도 표기(레벨·단계), 연속/스트릭 표현이
  섞이면 즉시 폐기하고 준비된 칭찬 문구로 대체.
- 분석 실패 시에도 완료는 그대로 인정된다.
