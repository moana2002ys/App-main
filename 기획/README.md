## 규칙

1. **구현 기준은 `정본/`뿐입니다.** `근거/`와 `아카이브/`는 참고용이며, 따라 만들면 안 됩니다.
2. **문서와 코드가 다르면 코드가 최신입니다.** 이 프로젝트는 앱이 문서보다 앞서 발전했습니다. 차이를 발견하면 `00_결정필요_안건.md`에 기록하고 정본을 고치세요.
3. **같은 규칙을 두 문서에 복사하지 마세요.** 한쪽만 고쳐져 충돌이 생깁니다. 정본에 쓰고 다른 곳에서는 링크로 가리키세요.
4. 결정을 내렸으면 `00_결정필요_안건.md`의 **결정 기록 표**에 남기세요.
