## 0. 설계 원칙

1. **행동이 먼저, 기분은 따라온다** — 모든 화면의 카피와 흐름이 이 모델을 반복 학습시킨다.
2. **계획은 가볍게, 실행은 즉시** — BA의 약점(과도한 계획 수립)을 보완한다. 계획 입력은 "탭 한 번" 수준으로 제한하고, 계획 직후 바로 실행 가능한 형태(오늘·시간대·더 작은 버전)로만 세운다. 계획 화면과 실행 화면 사이의 단계를 최소화한다.
3. **성공확률 최대화(graded task)** — 실패 경험을 만들지 않는 것이 최우선. 난이도는 항상 낮은 쪽이 기본값.
4. **입력 부담 최소화** — 시간대별 표 지양, 탭 중심(리서치의 구현 원칙 그대로).

## 1. 현재 사이클 진단 (BA 8대 핵심 성분 대응)

| BA 핵심 성분 (Huguet et al., 2016) | 현재 상태 | 개선 방향 |
|---|---|---|
| (1) 우울/BA 심리교육 | 없음 | 온보딩 스토리텔링 카드 |
| (2) 활동–기분 모델 설명 | 없음 | 온보딩 + 데일리 설문의 "어제 조각 후 기분" 문항 |
| (3) 기분 평정 | 데일리 설문에 있음 | 유지 (탭 1회) |
| (4) 활동 모니터링 | 완료 기록만 존재, 기분과 미연결 | 완료 시점의 P/M 평정을 기록과 함께 저장 |
| (5) 즐거움(P) 평정 | "도움이 된 것 같나요?"로 유사 대체 | 표준 P 슬라이더로 교체 |
| (6) 숙달감(M) 평정 | "부담감" 문항으로 유사 대체 | 표준 M(뿌듯함) 슬라이더로 교체 |
| (7) 즐거운 활동 스케줄링 | 랜덤 2개가 역할 못 함 | 즐거움 미션 슬롯 신설 |
| (8) 회피 활동 스케줄링 | 없음 | 회피 미션 슬롯 신설 + 회피 수정 프롬프트 |
| 강화/피드백 | 통계 나열 수준 | 기분 곡선 × 완료 조각 오버레이 그래프 |

## 2. 개선된 사이클

### 2-1. 온보딩 (신규 재구성, 약 1주일)

**Phase A — 스토리텔링 심리교육 (Day 0, 5분 이내)**
- 조각이의 이야기로 활동→기분 모델을 전달: "기분이 나아지면 움직이자 ✗ / 일단 움직이면 기분이 따라온다 ✓".
- 회피의 악순환 고리(안 움직임 → 좋은 것의 통로 차단 → 더 가라앉음)를 짧은 카드 2~3장으로.
- 교육 직후 **가치 명료화**: 4개 영역(생활 리듬·자기 돌봄·관계·사회 진입)마다 "나에게 왜 중요한가"를 탭으로 선택. 이후 모든 미션 제안에서 "당신이 고른 ○○을 위한 조각"으로 연결(BA 장기 효과의 핵심).

**Phase B — 1주 온보딩 미션 (Day 1~7)**
- 하루 1개, 실패가 거의 불가능한 초소형 미션(커튼 걷기, 물 한 잔 등) + 스토리 진행.
- 매일 기분 + 미션 후 즐거움(P)/뿌듯함(M)을 탭으로 기록.
- **이 1주간의 데이터가 "나의 시작 데이터"로 저장**되어 본 챌린지의 개인화 기반이 된다:
  - 기분 베이스라인 → 이후 변화 그래프의 기준선
  - P/M 응답 패턴 → 즐거움 미션 슬롯의 초기 추천 근거
  - 미션 완료/건너뜀 패턴 → 회피 미션 슬롯의 초기 난이도 설정
- 계획 과잉 방지: 온보딩 기간에는 계획 입력이 아예 없음. "오늘의 미션"이 이미 정해져 있고, 하거나/건너뛰거나만 존재.

### 2-2. 데일리 설문 (수정)

| 문항 | 형식 | BA 성분 |
|---|---|---|
| 오늘의 기분/컨디션 | 탭 1회 | (3) 기분 평정 |
| 도전하고 싶은 영역 (타깃 카테고리 하위 영역만) | 탭 | 가치 연결 |

**관심사 문항 처리 (2026-07-20 결정):** 삭제가 아니라 **이동**. 관심사(음악·동물 등 취향 소재)는 미션 문구 개인화의 콜드스타트 입력으로 여전히 필요하지만, 취향은 매일 바뀌지 않으므로 데일리에서 묻지 않는다.
- 온보딩에서 수집 + 주 1회 가벼운 갱신("요즘 빠져있는 게 있나요?")
- P 평정이 높았던 미션의 소재를 관심사 풀에 자동 추가(데이터가 쌓이면 질문 빈도 자체를 줄임)
- 결과: 데일리 설문은 **2문항**(컨디션 + 영역/활동 선택)으로 고정.

> **주:** "활동 후 기분"은 데일리 설문이 아니라 **사후 설문의 P/M 즉시 평정**이 담당한다(BA 표준: 평정은 활동 직후). 활동–기분 연관 **자각**은 별도 문항이 아니라, 매일의 기분 기록과 P/M 기록을 겹쳐 보여주는 마이페이지 그래프(강화/피드백)가 만든다 — 문항 중복과 입력 부담을 피하는 근거 기반 선택.

### 2-3. 미션 제안 (4개 슬롯 구조 변경)

| 슬롯 | 기존 | 개선 |
|---|---|---|
| 1–2 | 사용자가 고른 영역 2개 | 유지 + "당신의 가치 ○○과 연결" 문구 |
| 3 | 랜덤 | **즐거움 미션**: 과거 P 평정이 높았던 활동 유형에서 추천 — (7) |
| 4 | 랜덤 | **회피 미션**: 반복 건너뜀/미룸 영역을 **더 작게 쪼갠 버전**으로 — (8) |

각 미션 공통:
- **난이도 단계 선택(가볍게/보통/도전)** — graded task. 기본값은 항상 "가볍게".
- **선택 즉시 초경량 계획**: "오늘 언제 하실래요?" 아침/점심/저녁 탭 1회. 끝.
  - 시간·장소·순서를 쓰게 하지 않는다. 계획-실행 연결은 리마인더 푸시(선택한 시간대 시작 시점)가 담당.
  - → "계획만 세우다 끝나는" BA의 함정을 피하면서 activity scheduling의 회피 방지 효과는 유지.

### 2-4. 완료 인증 + 사후 설문 (수정)

- 완료 버튼 → 축하 피드백.
- **P/M 이중 평정으로 교체**: "얼마나 즐거웠나요?"(P) + "얼마나 뿌듯했나요?"(M) 슬라이더 2개 — (5)(6).
  - 기존 "부담감" 문항은 난이도 단계 선택 데이터로 대체, "도움됨" 문항은 P/M이 대체.
- 챌린지별 맞춤 주관식 1문항(선택) 유지, 사진 인증(선택) 유지.
- **[신규] 건너뜀 처리 = 회피 수정 프롬프트**: 미완료 시 벌점 없이 "어떤 게 발목을 잡았나요?"를 탭 선택지(시간이 없었어요/시작이 무거웠어요/기분이 가라앉았어요 등)로 수집 → 다음 제안 때 같은 미션의 **더 작은 버전**이 회피 슬롯에 재등장. (TRAP→TRAC의 경량 구현)

### 2-5. 마이페이지 (강화/피드백 강화)

- **핵심 신규 요소: 기분 곡선 × 완료 조각 오버레이 그래프** — "움직인 날 기분이 올라갔다"를 직접 눈으로 확인시키는 것이 BA에서 가장 강력한 강화 장치. 온보딩 1주 베이스라인이 기준선으로 깔린다.
- 영역별 완료 통계(기존 유지) + P/M 누적 평균을 영역별로 함께 표시 → "나는 관계 조각에서 즐거움이 높다" 같은 자기 발견.
- 함께한 날/~~연속 참여~~/포인트 유지(게이미피케이션은 보조 수단 원칙 그대로).
  - **[2026-07-25] "연속 참여" 표시는 불변 원칙 "스트릭(연속) 메커니즘 금지"(설계명세 §1-1)와 정면 충돌한다.**
  - ⚠️ **그런데 현재 앱에 실제로 구현·노출되어 있다.** 처리 방향은 `정본/스토리_보상_설계.md` §6 및 `00_결정필요_안건.md` B4 참조. (2026-07-25 최초 조사에서 "미구현"이라 기록했으나 **오류**였음)

## 3. 데이터 흐름 요약

```
온보딩(가치 선택, 1주 기분·P/M 베이스라인, 완료 패턴)
   ↓
데일리 설문(기분 + 영역/활동 선택, 2문항)
   ↓
미션 제안(선택 2 + 즐거움 1[P 데이터] + 회피 1[건너뜀 데이터]) + 난이도 + 시간대 탭
   ↓
수행 → 인증(P/M 평정) 또는 건너뜀(회피 프롬프트)
   ↓
마이페이지(기분×활동 그래프로 강화) → 다음 날 설문의 동기로 순환
```

## 4. "계획 과잉" 조율점 정리

| BA 원전 | 우리 조율 |
|---|---|
| 활동을 미리 세세하게 계획 | 시간대 탭 1회 + 리마인더로 대체 |
| 주간 활동표 작성 | 없음 — 오늘의 4개 제안만 |
| 가치→활동 매핑 워크시트 | 온보딩 1회 탭 선택으로 압축, 이후엔 문구로만 상기 |
| 회피 패턴 분석 | 건너뜀 시 탭 1회 프롬프트 → 시스템이 자동으로 다음 미션에 반영 |

## 5. BA "계획 수립" 요소 대조표 — 무엇을 넣고 무엇을 뺐나

BA에서 activity scheduling이 요구하는 계획 요소와 우리 반영 현황. 사용자가 직접 결정하는 것은 **무엇을 / 얼마나(난이도) / 언제** 3가지로 한정하고, 나머지는 시스템이 대신 짊어진다.

| BA 계획 요소 | 우리 설계 | 판단 |
|---|---|---|
| 무엇을 (가치 기반 활동 선택) | 미션 4개 중 선택 + 온보딩 가치 연결 | ✓ 반영 |
| 난이도 조절 (graded task) | 가볍게/보통/도전 + 기존 단계·밴드 시스템 | ✓ 반영 |
| 언제 (구체 시각 지정) | 시간대 탭(아침/점심/저녁) + 리마인더 | ✓ 경량 반영 (의도적 완화) |
| 장애물 예상 (사전 TRAP 분석) | 사전 없음 → 건너뜀 시 회피 프롬프트(사후) | △ 사후 반영 (사전 예상은 계획 과잉이라 판단) |
| 어디서 / 누구와 | 없음 → **후반 단계에 도입** (아래) | △ 단계별 점진 도입 |
| 주간 활동표 작성 | 없음 → **비위험군에서 선택형으로** (아래) | △ 단계별 점진 도입 |

### 5-1. 계획 깊이의 단계별 점진 도입 (2026-07-20 결정)

BA 프로토콜(예: BATD) 자체가 회기 구조로 계획 요소를 하나씩 얹는 방식이므로, "어디서/누구와/주간표"는 영구 생략이 아니라 **후반 단계로 미룬 것**으로 재정의한다. 계획의 깊이를 난이도처럼 graded하게 올린다:

| 회복 단계 | 계획 입력 |
|---|---|
| 은둔 · 고도고립 | 시간대 탭만 |
| 고립위험군 | + "어디서" 탭 (내 방/거실/집 밖 — 외출 게이트 연동) |
| 비위험군 | + "누구와" 탭, 선택형 주간 미리보기("이번 주 해보고 싶은 조각 미리 골라두기") |

### 5-2. 난이도 결정 구조 — 하이브리드 유지 (2026-07-20 결정)

BA 원전의 난이도 결정은 치료자–내담자 **협업**이다. 우리 구조가 이를 그대로 구현한다: **알고리즘의 밴드가 범위를 정하고(치료자 역할), 사용자는 그 안에서 가볍게/보통/도전을 고른다(내담자 역할).** 기존 단계·밴드 시스템은 핵심으로 유지.

- 자율 선택의 함정("계속 가볍게만") 대응: 선택권 박탈이 아닌 **기본값 넛지** — 가볍게를 연속 완료했고 P/M이 높으면 다음 제안에서 '보통'이 미리 선택된 상태로 제시. 고르는 자유는 항상 유지.

## 6. 기분–활동 연관 자각의 노출 전략 (이중 구조)

| 위치 | 형태 | 역할 |
|---|---|---|
| 사이클 안 (사후 설문 P/M 입력 직후) | 한 줄 마이크로 피드백: "이번 주, 조각을 맞춘 날 기분이 평균 한 칸 높았어요" | push형 — 반복 노출로 자각 형성. 마이페이지 미방문 유저도 커버 |
| 마이페이지 | 기분 곡선 × 완료 조각 누적 그래프 | pull형 — 스스로 탐색하는 회고·강화 |

**가드 조건:** 상관이 아직 나타나지 않거나 부정적인 기간에는 사이클 내 한 줄을 노출하지 않는다(억지 긍정 프레이밍 금지 — "실패 처벌 없음" 원칙의 연장).

## 7. 누적 데이터의 적극 활용

### 7-1. 단계 진급 기준 (앱 내부 — 현 알고리즘의 빈칸)

현 알고리즘에는 일 단위 밴드 조정(`adjustBandNextDay`)만 있고 회복단계(은둔→고도고립→고립위험군→비위험군) **진급 규칙이 없다.** 제안:

- **지표**: 최근 2주 완료율 / 타깃 영역 미션 성공 횟수 / M(뿌듯함) 추세 / 기분의 온보딩 베이스라인 대비 상승 / 게이트 행동(외출·대면·전화) 성공 여부
- **예시 규칙**: 2주 완료율 ≥ 60% AND 타깃 영역 3회 성공 AND M 추세 상승 → 다음 단계 **제안**
- **자동 승급 금지**: "다음 조각으로 넘어가볼까요?" 동의 탭으로 본인이 결정(강도 결정에 개인 의사 반영 = BA 원칙). 거절하면 2주 뒤 재제안.
- 하향은 기존 규칙(2일 연속 미완료 → L1 리셋) 유지, 단계 강등은 없음.
- 기존 밴드 조정의 "부담 응답" 입력은 난이도 선택 + P/M 데이터로 대체 가능 → 사후 설문 문항 순증 없음.

**규칙 → 학습 모델 로드맵:**
1. **1단계 (출시~)**: 수기 규칙만. 데이터가 적을 때 ML은 불안정하고, 임상 인접 판단은 설명 가능성이 필수(기관에 "왜 진급했나" 답변 가능해야 함).
2. **2단계 (데이터 축적 후)**: 의사결정트리 등 해석 가능한 모델을 **조언자**로 도입 — 규칙의 임계값을 사용자군별로 보정·개인화하는 용도. 최종 진급은 여전히 규칙 + 본인 동의 탭이 결정. 블랙박스가 단계를 정하는 구조 금지.

**정체 유저 대응 (어떤 기준이든 정체는 발생한다):**
1. 단계는 비노출이므로 체감 문제는 콘텐츠 반복감 → 같은 단계 안의 **수평 진행** 설계(새 활동 카테고리 개방, 같은 영역의 더 깊은 미션)로 정체 중에도 성장감 제공.
2. 4주+ 무진전 시 더 높은 문턱이 아니라 **대안 경로** 트리거: 미션 스타일 전환, 관심사 재수집, 난이도 재보정.
3. 장기 정체는 그 자체로 신호 → 기관 대시보드 위험 신호(7-2)로 연결, 개입 포인트로 활용.

### 7-2. 연계 기관 모니터링 대시보드 (외부 — 초안)

| 모니터링 항목 | 판단 요인 |
|---|---|
| 기분 추이 | 온보딩 베이스라인 대비 변화, 주간 이동평균 |
| 참여율 | 데일리 설문 응답률, 미션 완료율 |
| 회피 패턴 | 건너뜀 사유 분포, 반복 회피 영역 |
| 진행 상태 | 단계/밴드 변화 이력, 영역별 완료 분포, P/M 추세 |
| **위험 신호 (알림)** | N일 연속 미응답, 기분 급락, 장기 정체(단계·기분 모두 4주+ 무변화) |

**공유 범위 원칙**: 개별 미션 내용, 주관식 서술, 사진은 제외. 집계·추세 데이터만. 반드시 사용자 명시 동의 기반, 동의 철회 가능.

## 9. §5 확정 설계 검토 반영 (2026-07-20 확정)

별도 확정 설계 문서(§5 확정 규칙안)의 구조 결정 — **M→밴드 / P→즐거움 슬롯 분리**, 회피 슬롯 2주차 활성화, "완료→하향 칸 없음", diversity_key 3축, 보수적 진급 트리거(3조건 AND) — 을 전부 수용한다. 검토에서 추가로 확정한 보완 5건:

### 9-1. `day_result` 3분기 (사각지대 제거)

타깃 외 활동만 한 날이 "미완료(−1)"로 처리되는 문제 수정. 미완료 경로를 둘로 분리:

| 그 날의 결과 | ΔB | 연속 미완료 카운터 |
|---|---|---|
| 타깃 슬롯 1개 이상 완료 | 조정표 완료 행 적용 | 리셋 |
| **즐거움/회피 슬롯만 완료** | **0 (유지)** | **리셋** |
| 아무것도 완료 안 함 | −1 | +1 |

근거: "무활동"과 "타깃 외 활동"은 다른 신호. 뭔가를 한 날에 밴드가 내려가면 "실패 처벌 없음"이 집계 레벨에서 깨진다.

### 9-2. 진급 완료율 분모에서 회피 슬롯 제외

회피 슬롯은 정의상 *이미 건너뛰던 것*을 담으므로 분모에 넣으면 회피에 도전하는 유저일수록 진급이 늦어지는 역설 발생. **분모 = 타깃+즐거움 슬롯 제안 수. 회피 슬롯 완료는 분자에 보너스로만 인정.**

### 9-3. skip의 조작적 정의

- **명시적 skip** = 건너뛰기 탭 또는 회피 프롬프트("어떤 게 발목을 잡았나요?") 응답 → 회피 슬롯 후보 자격(2주 내 2회) 카운트에 **포함**.
- **무응답일**(앱 미접속 포함) = 회피 데이터에서 **제외**, 밴드의 미완료 경로에는 포함.
- 근거: 무응답까지 skip으로 치면 며칠 미접속한 유저의 회피 슬롯이 엉뚱하게 채워진다.

### 9-4. 저M 완료 연속 시 토글 복귀 넛지

조정표 행 4(완료 & M≤2)가 **연속 2회**면: 다음날 토글 기본값을 '가볍게'로 복귀. 밴드 불변·선택권 유지, 체감 부담만 완화 — 상향 넛지(nudge_streak)와 대칭.

### 9-5. 진급 조건 3 콜드스타트 임계 완화

첫 평가 기간의 "M평균 ≥ 3.5"는 5점 척도에서 과도하게 높음 → **첫 평가 기간은 조건 3 면제(조건 1·2 AND만 적용)**로 확정. false-positive 방어는 조건 1·2만으로도 충분히 보수적.

### 9-6. P/M 평정 UI = 슬라이더 유지

5점 탭이 아니라 **기존 연속 슬라이더(0–10) 유지** (사용자 결정). 내부 저장 시 5구간으로 매핑(§8-4)해 조정표·진급 임계와 정합. 슬라이더의 연속감이 "평가받는 느낌"을 줄이는 장점도 있음.
