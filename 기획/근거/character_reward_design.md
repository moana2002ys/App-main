# 캐릭터 성장 · 뱃지 · 해금 보상 설계

> 목적: 미션 반복 → 뱃지 → 캐릭터 아이템 해금·장착의 규칙을 정의한다.
> 원리: 반복된 성공 경험이 자기효능감을 만든다(Bandura). 캐릭터가 자라는 것 = 그 성장을 눈에 보이게 하는 것.
> MVP 범위: 상점 제외. **뱃지 → 아이템 자동 지급·장착**까지. 포인트는 누적 표시만(상점은 이후).

---

## 0. 안전·설계 원칙 (이 인구에 필수)

1. **누적, 리셋 없음**: 뱃지는 누적 카운트로만. 연속(streak) 기준 금지 — 하루 놓쳐도 진척이 사라지지 않는다. (재고립 취약, 실패 무벌점)
2. **회수 없음**: 획득한 아이템·뱃지는 절대 사라지지 않는다. 손실 회피 자극 금지.
3. **더하기만**: 캐릭터는 늘 뭔가를 얻고 잃지 않는다. 미완료를 캐릭터에 반영하지 않는다.
4. **무낙인·무경쟁**: 뱃지 이름에 고립/은둔/등급 언어 금지. 타인 비교·랭킹 없음.
5. **성장 프레이밍**: "OO이 익숙해졌어요"처럼 *네가 자랐다*로 표현. 시스템이 준 게 아니라 네가 해낸 것.
6. **관계 아이템은 부드럽게**: 관계 영역 보상은 '친구 무리' 같은 압박 이미지 금지. 창밖 손인사·편지·따뜻한 소품 정도로.

---

## 1. 반복 주기 — 미션 엔진의 '느슨한 집중'

무작위로 흩뿌리지 않고 **한 카테고리에 며칠 머문다.**

```
카테고리 선택(회복단계 허용영역 + 오늘 희망영역)
   → 그 안에서 조금씩 다르고 조금씩 어려운 미션을 매일 제공 (변주 엔진)
   → 누적 3회 달성 시 뱃지 + 아이템
   → 다음 카테고리로 확장
※ 데일리 설문에서 다른 희망영역을 고르면 그쪽으로 방향 전환(자율성 존중)
```

- "반복"이 곧 **난이도 사다리 오르기**가 된다. 예) 산책 카테고리: 창문 5분 → 현관 앞 → 편의점. 3회 = 사다리를 올랐다는 증거.
- 같은 카테고리라도 매일 미션이 달라 지루하지 않다(취향·형식·시간대·소재 변주).
- 한 카테고리 집중 기간 ≈ **3~7일**(하루 1미션, 일부 미완료 감안).

---

## 2. 뱃지 기준

### MVP (단일 임계값)
- **누적 3회 완료 → 해당 카테고리 뱃지 + 아이템 자동 지급·장착**
- 누적, 리셋·만료 없음. 연속 조건 없음.
- 근거: 1~2회는 자기효능감이 안 붙고(사소한 성공), 10회+는 취약 인구에 너무 멂. **3회**가 초반 보상 + 최소 숙달 증거의 균형점. 데모 [다음날로] 3번이면 시연 가능.

### 확장 (시간 남으면 · 데모 후)
- Tier 2 — 누적 **7회**: 아이템이 '자라거나' 색이 생김(업그레이드)
- Tier 3 — 누적 **15회**: 숙달 버전 + 배경 요소
- 그래도 전부 누적·무리셋.

### 기본 캐릭터
- 생성 시 기본 외형을 이미 갖춤(맨몸 금지). 뱃지는 여기에 **더해지는** 방식.

---

## 3. 카테고리 → 뱃지 → 아이템 매핑

시각적으로 의미 있는 카테고리에 아이템을 건다. 추상 카테고리(하루 구조화·자기연민 등)는 아이템 대신 배경 분위기/포인트로.

| 영역 | 카테고리 | 뱃지(성장 프레이밍) | 캐릭터 아이템 |
|---|---|---|---|
| 생활리듬 | 빛과 공기 | 아침이 밝아졌어요 | 열린 커튼 · 창가 햇살(배경 밝아짐) |
| 생활리듬 | 식사 리듬 | 끼니와 친해졌어요 | 식탁 · 따뜻한 밥/컵 |
| 생활리듬 | 기상·취침 앵커 | 하루의 시작점이 생겼어요 | 알람시계 · 정돈된 침대 |
| 자기돌봄 | 위생·몸단장 | 산뜻해졌어요 | 빗/거울 · 깔끔한 모습 |
| 자기돌봄 | 감정 자각·기록 | 마음을 들여다보게 됐어요 | 일기장 + 펜 |
| 자기돌봄 | 몸 움직이기 | 몸이 가벼워졌어요 | 요가매트 |
| 자기돌봄 | 바깥과 연결(산책) | 산책이 익숙해졌어요 | **운동화** ★ |
| 자기돌봄 | 공간 돌보기 | 공간이 정돈됐어요 | 정돈된 방 코너 |
| 자기돌봄 | 취향·몰입 | (취향과) 가까워졌어요 | 취향별: 음악=헤드폰 · 책=책더미 · 식물=화분 · 게임=게임패드 · 그림=이젤 · 동물=반려동물 · 요리=앞치마 · 스포츠=공 |
| 관계 | 비대면~자조 사다리 | 세상과 조금 이어졌어요 | 말풍선 · 창밖 손인사(부드럽게) |
| 관계 | 신뢰 인물 | 마음을 나눴어요 | 편지 · 따뜻한 소품 |
| 사회진입 | 관심·강점/정보/자기표현 | 나를 찾아가고 있어요 | 노트북 · 노트 · 가방 |

> 취향·몰입은 사용자의 관심사에 따라 아이템이 갈린다 → 캐릭터가 그 사람다워짐(반복할수록 취향이 더 드러남).

---

## 4. 배경 확장 = '여정'(발자국 경로의 역할 대체)

캐릭터 아이템이 '나를 꾸미는 것'이라면, 배경은 '세상이 넓어지는 것'이다. 외출·사회진입 성취에 연동해 조용히 확장.

```
방 안  →  방 밖(집 안)  →  현관·창밖  →  동네
```
- 트리거 예: 산책 뱃지 → '방 밖' 배경 / 사회진입 첫 뱃지 → '동네' 배경.
- 팝업 없이 은은하게 바뀐다. 이게 예전 '발자국 경로'가 하던 여정 표현을 캐릭터 세계로 흡수한 것.

---

## 5. 포인트 (MVP: 누적 표시만)

- 미션 완료 시 포인트 지급(난이도 가중 예: L1=5 … L5=25).
- MVP: 누적 카운터로 표시. **상점·구매는 이후 단계.**
- 향후: 뱃지가 카테고리를 '해금'하면, 포인트로 그 안의 변형 아이템(운동화 색/종류 등)을 상점에서 구매.

---

## 6. 데이터 (최소 스키마 추가분)

```json
// 기존 users/missions/mission_logs 에 더함
"category_counts": { "SELF-2D": 3, "LIFE-1B": 1 },   // 카테고리별 누적 완료(리셋 없음)
"badges": ["SELF-2D"],                                // 획득 뱃지(회수 없음)
"equipped_items": ["운동화"],                          // 자동 장착
"points": 45,                                          // 누적 표시용
"background_stage": "방 밖"                             // 배경 확장 단계
```
완료 처리 로직: `category_counts[cat] += 1` → `== 3`이면 `badges.push(cat)` + 아이템 지급·장착 + (해당 시) 배경 확장.

---

## 7. 데모 시연 포인트

- [다음날로] 3번 → 같은 카테고리 미션이 조금씩 달라지며 등장 → 3회째에 **뱃지 + 운동화가 캐릭터에 붙는 장면**.
- 심사 메시지: "반복이 곧 난이도 사다리였고, 캐릭터가 자란 만큼 사용자가 자란 것" = 적응형 + 자기효능감을 한 컷에.
