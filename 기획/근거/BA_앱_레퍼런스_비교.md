# BA 기반 앱 레퍼런스 비교 (조각조각 설계 참고용)

_작성: 2026-07-24 · 목적: 행동활성화(BA)·게임형 셀프케어 앱 사례를 우리 챌린지 사이클 설계와 대조. 근거는 peer-review 저널·공개 자료 기준._
_스크린샷: 각 앱 섹션의 "캡쳐 대상" URL 참고. (캡쳐 슬롯 `〔이미지〕`는 채워 넣으면 됨 — 필요하면 브라우저로 대신 캡쳐 가능.)_

**요약 시사점:** 임상 근거(B-ACT·Moodivate)와 몰입 설계(Finch)는 대체로 **다른 앱**에 나뉘어 있다. 우리의 포지션 = **B-ACT급 BA 충실도 + Finch급 스토리·처벌없는 몰입 + (남들에게 없는) 적응형 난이도·최소 입력**. 이게 차별점.

## 1. B-ACT (ROWAN Inc., 한국) — 우리와 가장 가까운 레퍼런스 ★
_출처: Frontiers in Psychiatry 2025, "A behavioral activation mobile application for depression among Korean young adults" (pilot, 멀티모달 사용패턴+임상결과)._
_캡쳐 대상: 논문 Figure(앱 스크린샷)_ https://www.frontiersin.org/journals/psychiatry/articles/10.3389/fpsyt.2025.1707034/full

〔이미지: 앱 화면 캡쳐〕

**설계 세부:**
- **활동 카탈로그 441개** — Pleasant Events Schedule(PES)를 한국 문화로 현지화(예: "크리켓"→"야구", "맛집 탐방"). 사용자 직접 추가 가능.
- **6개 생활 영역**: 대인관계 / 교육·진로 / 취미·여가 / 건강·종교 / 일상활동 / 자기돌봄.
- **주 3차: 가치 명료화** — 6영역 중요도 평정 후, **가치 기반 미션** 설정(기대·중요도·난이도 3평정). *비적응.*
- 주간 심리교육 영상(순차 해금, 필수).
- **가치–행동 정렬 레이더 차트**(실제 활동 분포 vs 자기보고 가치), 7주차 "My Journey" 리포트.
- 8개 기분 상태로 활동 평정, 한국 정서규준 기반 valence 점수.
- 코인(활동 로깅·영상 시청) · 아바타 꾸미기 · 뱃지.

**사용 패턴·결과:** 주 5.67회 로그인, 주 27.73개 활동 기록, **완주율 87.2%.** 핵심: **"긍정 활동 참여가 많을수록 증상 감소가 가팔랐다"** — 단, 전체 활동 수는 임상 개선과 음의 관계(무작정 많이 하는 건 도움 안 됨).

**우리가 배울 것 / 다르게 할 것:**
- 배울 것: PES 현지화 활동 뱅크, 가치–행동 정렬 시각화(우리 마이페이지 오버레이와 유사), 높은 완주율의 대면 온보딩.
- 다르게: B-ACT는 **활동당 3평정(기대·중요·난이도) = 입력 부담 큼** + **비적응**. 우리는 **최소 입력(토글+P/M) + 적응형 밴드**로 간다. "긍정 활동이 핵심" 발견은 우리 **즐거움 슬롯 + P→즐거움 추천**을 뒷받침.

## 2. Moodivate (Dahne / MUSC) — 임상 근거 최강
_출처: MUSC 2025 발표, ScienceDirect pilot RCT(S0005789418301576)._
_캡쳐 대상:_ https://research.musc.edu/content-hub/news/2025/04/14/mood-improving-app · 앱스토어 "Moodivate"

〔이미지: 앱스토어 스크린샷〕

- 자기주도(치료자 불필요) BA 앱. 1차진료 22곳 RCT: 표준치료 대비 **우울 개선 약 2배, 관해 2.3배, 임상적 호전 3배.**
- 활동 스케줄링 중심, 리마인더 기반.
- **배울 것:** "치료자 없이 자동 BA도 효과"의 강한 근거 → 우리 규칙기반+LLM 자동화의 타당성.
- **다르게:** 임상 톤(게임화 약함) → 우리는 스토리·캐릭터로 지속 동기.

## 3. MoodMission — 참여(engagement) 패턴 연구
_출처: Behavioural and Cognitive Psychotherapy 2021 (Cambridge), PubMed 34396942._
_캡쳐 대상:_ 앱스토어 "MoodMission"

〔이미지〕

- 저기분·불안에 BA+CBT 기반 "미션" 추천. 238명 30일 사용 분석.
- **배울 것:** 어떤 미션이 반복 사용되는지의 engagement 데이터 관점 → 우리 미션뱅크 튜닝·완료율 해석에 참고.
- **다르게:** 미션 추천이 적응형 난이도는 아님.

## 4. Finch — 처벌 없는 게임형 몰입(넛징 레퍼런스) ★
_출처: Deconstructor of Fun 등._
_캡쳐 대상:_ https://finchcare.com · 앱스토어 "Finch: Self-Care Pet"

〔이미지: 홈(펫)·위젯·보상 화면〕

**핵심 루프:** Trigger → Action(작은 셀프케어) → Reward(에너지·의상·방 꾸미기) → Progress(펫 진화·새 지역 해금·모험).
- **펫 돌보기 = 감정적 몰입 동력.** 온보딩이 기능 나열이 아니라 **펫 부화**로 시작.
- **타이머 기반 모험**(완료 후 펫이 모험을 떠남) = 강요 없는 재방문 창.
- **위젯 4장치:** 살아있는 펫 상태 / 모험 진행·완료 / 진행바 / 마이크로 이벤트(아침 체크인·저녁 대화 보상·깜짝 친구 방문).
- **compassionate design:** Duolingo식 streak-loss 처벌 없음 — 하루 놓쳐도 죄책감 대신 복귀 유도. 알림도 "nagging" 회피.

**우리가 배울 것 / 다르게 할 것:**
- 배울 것: 펫 돌보기·진화·세계확장(우리 캐릭터/배경 확장과 동일 계열), **처벌 없는 설계**(우리 §1 원칙과 정합), 아침/저녁 마이크로 이벤트(우리 리마인더 §6-7 저녁 체크인과 일치).
- 다르게: Finch는 BA 앱이 아님(임상 근거 약). 우리는 **BA 엔진(적응형·즐거움/회피 슬롯)** 위에 Finch식 몰입을 얹음. 또 가변 보상(변주)은 취약 인구라 **예측 가능한 누적 보상**으로 절제(§2-1).

## 5. 기타 프레임 (참고)
_출처: `reference/행동 활성화 리서치.pdf`._
- **Actify!**: BA 근거 제공 + 가치 식별 + 가치기반 활동 계획·스케줄링 + 실행 모니터링.
- **MEndorphins**: 모니터링 + 계획 + 피드백 + 공유.
- **B-ACT(동명, 위 1과 별개 프레임 표기)**: 활동 모니터링 + 가치기반 목표 + 강화(보상/피드백).
- 공통: 표준 8성분 전부가 아니라 **앱 목적·톤에 맞게 일부 선택**. 우리도 동일(심리교육·가치·P/M·즐거움·회피·강화 채택, 계획은 최소).

## 6. 종합: 조각조각의 차별 포지션

| 남들이 가진 것 | 남들이 약한 것 | 우리가 메우는 것 |
|---|---|---|
| 임상 근거(B-ACT, Moodivate) | 적응형 난이도 | **밴드 + 회고 기반 day_result 조정** |
| 몰입 설계(Finch) | BA 충실도 + 임상 톤 | **즐거움/회피 슬롯 + 스토리형 캐릭터** |
| 활동 카탈로그(B-ACT 441) | 저입력 | **탭 중심 최소 입력(토글+P/M 슬라이더)** |
| 게임화(코인·아바타) | 처벌 없음 원칙의 일관성 | **누적·무회수·무리셋 + 낙인 언어 0** |

한 줄: **"B-ACT의 BA 충실도 × Finch의 처벌 없는 몰입 × (우리만의) 적응형·최소입력"** — 은둔·고립 청년에 맞춰.

## 7. 캡쳐 체크리스트 (세세 비교용)
각 앱에서 아래 화면을 잡으면 우리 사이클 단계와 1:1 대조가 됨:

| 앱 | 캡쳐할 화면 | 우리 대응 |
|---|---|---|
| B-ACT | 활동 선택 / 가치 명료화 / 레이더 차트 / My Journey | 데일리 설문 / 가치(§5-1) / 마이페이지 오버레이 |
| Moodivate | 활동 스케줄 / 리마인더 | 미션 제안 / 리마인더(§6-7) |
| MoodMission | 미션 목록 / 미션 상세 | 4슬롯 미션(§6) |
| Finch | 펫 홈 / 보상·진화 / 위젯 / 저녁 체크인 | 캐릭터·보상 / 리마인더(§6-7) |

> 캡쳐는 앱스토어 상세페이지(스크린샷 다수 노출) 또는 각 공식 사이트가 편함. 원하면 제가 브라우저로 대신 캡쳐해 이 문서에 삽입 가능.
