---
name: 조각조각 미션 구성 규칙 보장 설계
description: 미션 규칙(한 활동, 취향 2+일반 1, 사진 인증 1+)은 프롬프트만으로 부족하고 결정적 가드가 필요하다는 교훈과 한국어 감지 오탐 주의점.
---

**핵심 교훈: LLM 프롬프트 규칙은 결정적(deterministic) 후처리 가드 없이는 지켜지지 않는다.**
프롬프트에 금지 표현·구성 규칙을 아무리 강하게 써도 LLM은 간헐적으로 위반한다("~틀어둔 채", 취향 3개 반영 등 실제 관측됨). 규칙마다 (1) 검증된 시드 뱅크, (2) 감지기(분류기), (3) 위반 시 시드 교체/재조정 패스의 3중 방어가 필요하다.

**Why:** 프롬프트만 강화하는 접근을 두 차례 시도했으나 반복 테스트에서 계속 위반 사례가 나왔고, 코드 리뷰에서도 "prompt-only는 보장이 아니다"로 두 번 반려됨.

**How to apply:** 미션 생성 규칙을 추가할 때는 프롬프트 수정과 함께 반드시 감지기+교체 로직을 넣고, 전체 시드·힌트 대상 오탐(FP) 감사와 취향×영역×조건 전수 불변식 테스트를 돌려 0 위반을 확인한다. 승격용 힌트 문구는 감지기가 스스로 분류할 수 있게(취향 토큰 포함) 작성한다.

**한국어 병렬 활동 감지 오탐 주의(핵심):**
- `~고 ` 연결형("커튼 열고 물 마시기")은 병렬이지만 명사 `냉장고/창고/광고`가 `고 `로 끝나 오탐 → 일반 `[가-힣]고\s` 금지, 흔한 동사 어간 화이트리스트 + `고\s`로만 검출. 보조용언 `~해 두고`도 병렬(어간 `두` 포함 필요).
- `~고 싶`(희망)은 단일 활동 → `(?!싶)` 제외.
- `~ㄴ 채(로)`("틀어둔 채 걷기")는 동시 진행 병렬. `채소` 오탐 방지: 관형형 어미 뒤 + `채` 다음이 공백/끝/(로)일 때만.
- `~ㄴ 뒤/후`("마신 뒤 점 찍기")는 순차 병렬. 위치 명사("책상 뒤") 오탐 방지: 관형형 어미 뒤 + 이어지는 활동이 있을 때만.
- 가운뎃점 `·`은 대개 명사 나열(단일). `A·B하기`처럼 두 행위가 한 '하기'에 붙고 `중/또는/택` 표지가 없을 때만 병렬 판정.
- `~아/어` 연접("골라 적기", "떠올려 적기")은 단일 과제로 보고 잡지 않는다.

**취향 분류 토큰은 고정밀(좁게):** 취향 판별 토큰을 넓게 잡으면(예: `읽`, `스트레칭`) 일반 시드가 취향으로 오분류되어 구성 재조정이 엉뚱한 교체를 한다. 취향 목록이 고정 선택지면 취향별 좁은 패턴이 안전하다.
