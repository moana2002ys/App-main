---

"한 미션 = 한 활동" 보장은 세 겹으로 이뤄진다(어느 하나만으로는 불충분):
1. **검증된 시드**: `lib/mission-bank/src/categories.ts`의 모든 시드는 단일 활동이어야 한다. 폴백/수리는 이 시드만 쓰므로, 시드가 깨끗하면 폴백 경로는 항상 안전하다.
2. **감지기** `hasParallelActivities` (engine.ts): LLM 출력의 병렬형을 잡는다.
3. **최종 검증 패스**: 라우트에서 수리 후에도 위반이 남으면 throw → 전체를 `selectFallbackMissions`(검증된 시드)로 교체.

**한국어 감지 오탐 주의(핵심):**
- `~고 ` 연결형(예: "커튼 열고 물 마시기")은 병렬이지만, 명사 `냉장고/창고/광고` 등이 `고 `로 끝나 오탐을 낸다 → 일반 `[가-힣]고\s` 금지. 흔한 **동사 어간 화이트리스트 + `고\s`**로만 검출.
- `~고 싶`(희망 보조용언, "먹고 싶은 것 검색")과 `하고 싶`은 단일 활동 → `(?!싶)`로 제외.
- 가운뎃점 `·`은 대개 명사 나열(단일 활동: "손·얼굴 씻기", "아침·낮·저녁 중 한 칸")이라 무조건 금지하면 오탐. `A·B하기`처럼 두 행위가 한 '하기'에 직접 붙고 `중/또는/택` 표지가 없을 때만 병렬로 판정.
- `~아/어` 연접("골라 적기", "살펴 파악하기")은 단일 과제 표현으로 보고 잡지 않는다.

**How to apply:** 시드 추가/수정 시 `하고/~고/그리고/및/+/A·B하기` 병렬형을 넣지 말 것. 감지기 수정 후에는 전 시드·INTEREST_HINTS를 대상으로 오탐(FP) 감사를 돌려 0을 확인.
