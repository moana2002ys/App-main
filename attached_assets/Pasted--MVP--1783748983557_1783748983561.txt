# 프로젝트: "나의 성장을 돕는 앱" — 적응형 회복 챌린지 웹앱 (MVP 프로토타입)

## 한 줄 정의
매일 사용자의 컨디션·희망 영역·관심사를 묻고, 규칙 분류기가 사용자 상태에 맞는 챌린지 3개를
제안하면 사용자가 1개를 골라 수행하고, 그 반응에 따라 다음 날 챌린지과 캐릭터가 성장하는 앱.

## 컨셉·톤
- 컨셉: "나의 성장을 돕는 앱". 성장 요소를 캐릭터로 시각화해 한눈에 보이게.
- 톤: 차분한 파스텔, 여백 넉넉히, 병원·진단 느낌 금지. 텍스트 짧게. 응원하되 재촉하지 않기.

## 절대 원칙 (반드시 지킬 것)
- 사용자에게 "고립"·"은둔"·"환자" 라벨을 절대 노출하지 않는다. 회복 단계는 내부 값으로만.
- 자유 대화형 챗봇을 만들지 않는다. 사용자-사용자 커뮤니티·랭킹·비교 기능 없음.
- 실패를 벌하지 않는다: 미완료 챌린지을 쌓아 보여주지 않고, 실패 기록을 강조하지 않는다.
- 화면 어디서나 눌리는 작은 [도움받기] 링크를 상단/하단에 항상 둔다(상담·지원 자원 안내 목업).
- 외부 DB·RAG·벡터DB 없음. 챌린지 데이터는 아래 챌린지 뱅크를 코드에 하드코딩.

## 기술 스택
- 프론트: React + Tailwind, 모바일 세로 폰 프레임 안에서 시연.
- 백엔드: 가벼운 Node 서버리스 함수 1개(LLM 호출 처리).
- LLM: Replit AI Integrations로 호출(오늘 구현, 별도 API 키 불필요, Replit 크레딧 과금).
  분류기가 정한 조건을 받아 오늘의 챌린지 3개를 생성한다. 호출 실패/지연 시에만 예시 뱅크로 즉시 대체(안전망).
- 상태 저장: 브라우저 메모리(React state)만. 외부DB·RAG 없음.

## 화면 흐름 (총 6개)
1) 온보딩 — 캐릭터 만들기 + 간이 진단(최초 1회)
   - 캐릭터 생성: 기본 캐릭터 1개 선택(색/모양 정도).
   - 진단 4문항(부드러운 말풍선 톤, 딱딱한 설문 금지):
     Q1 어제 몇 시쯤 잤나요? (밤낮 바뀜 / 새벽 / 자정 전후 / 규칙적)
     Q2 요즘 집 밖에 나가는 건 얼마나 부담되나요? (매우 부담 / 조금 부담 / 괜찮음)
     Q3 지금 편한 소통 방식은? (혼자가 편함 / 문자 / 전화 / 대면 괜찮음)
     Q4 지금 가장 신경 쓰이는 영역은? (하루 리듬 / 나 돌보기 / 사람 관계 / 일·진로 / 잘 모르겠음)
   - 결과: 회복 단계 + 금지조건을 내부 세팅(사용자에겐 안 보임).
2) 오늘의 데일리 설문(매일, 짧게)
   - 컨디션: "오늘 컨디션은 어때요?" (바닥 / 그저 그럼 / 괜찮음) → 오늘 난이도 보정
   - 희망 영역: "오늘은 어떤 걸 해보고 싶어요?" (4영역 중 1개; 잘 모르겠으면 단계 기본값)
   - 관심사(취향): "요즘 아주 조금이라도 궁금한 게 있다면?"
     (게임 / 음악 / 동물 / 식물 / 요리·먹는 것 / 책·글 / 스포츠 / 그림·만들기 / 잘 모르겠어요)
     → 챌린지 문구에 취향 반영.
3) 홈 — 오늘의 챌린지 3개 (같은 영역, 난이도 층위) → 1개 수락(필수)
   - 챌린지 카드 3장(게임의 데일리 챌린지처럼): 각 카드 = 챌린지 문구 + 영역 태그 + 예상 소요시간.
   - 사용자가 마음에 드는 1개를 [이거 할래요]로 수락. 나머지는 사라짐.
   - 상단: 캐릭터 미니뷰 + Day N.
4) 회고 — 완료 인증
   - [완료했어요] → 부담도 이모지(😌 쉬웠어요 / 😐 적당 / 😣 버거웠어요)
     + 만족도 이모지(👍 도움됐어요 / 🤔 그냥그럼 / 👎 별로)
     + 챌린지별 맥락 질문 1개(아래 표) + 한 단어 회고(선택)
   - 완료 시 포인트 획득 + 캐릭터에 챌린지 관련 아이템/변화 반영(아래 보상 규칙).
5) 캐릭터/성장 화면 (보상·인증의 핵심)
   - 내 캐릭터 크게 표시 + 지금까지 획득한 꾸미기 요소.
   - 누적 완료 수 / 연속 참여일 / 영역별 진척 바.
   - 챌린지을 할수록 캐릭터 꾸밈이 늘고, 활동 반경이 넓어짐(예: 산책 챌린지 → 운동화 지급, 방 안 → 방 밖 배경 확장).
   - 타이틀 획득 시 새 카테고리 해금(뱃지 느낌), 포인트로 해금된 카테고리 상점에서 아이템 구매.
   - (데모 필수 최소치: 캐릭터 1개 + 챌린지 완료 시 아이템 1개 붙기 + 포인트 증가. 상점/해금 전체는 시간 남으면.)
6) [다음 날로 →] 시뮬 버튼 (데모 전용, 눈에 띄게)
   - 누르면 하루가 지난 것으로 시뮬레이션 → 어제 회고 반영해 오늘 챌린지이 달라지고,
     캐릭터가 조금 성장한 모습을 즉시 보여줌. (적응형을 증명하는 핵심 시연 장치)

## 규칙 기반 분류기 (코드로 구현 · LLM 아님)
입력: 수면시각, 외출부담(상/중/하), 대인접촉부담(혼자/문자/전화/대면),
      오늘 컨디션(바닥/보통/괜찮음), 오늘 희망영역, 관심사,
      최근 챌린지 완료율, 직전 챌린지 부담도, 직전 챌린지 만족도.
출력(챌린지 규칙): { 회복단계, 챌린지영역, 난이도밴드, 금지조건[], 다음행동 }

(A) 회복 단계 판정 — 온보딩 직후 1회
- 외출부담=상 AND 대인=혼자        → 은둔        (기본밴드 L1, 금지: 외출·대면·전화·관계대면)
- 외출부담=중 OR 대인=문자          → 고도고립    (기본밴드 L1~2, 금지: 대면·전화·외출)
- 외출부담=하 AND 대인=전화/대면부담 → 고립위험군  (기본밴드 L2~3, 금지: 대면은 저강도만)
- 외출부담=하 AND 대인=대면 괜찮음   → 비위험군    (기본밴드 L3~4, 금지: 없음)

(B) 오늘 챌린지 영역 = 데일리 설문의 희망영역. (잘 모르겠음 → 회복단계 기본 우선영역)
    단, 금지조건에 걸리는 영역/난이도는 제외. 은둔·고도고립 초기에는 생활리듬·자기돌봄 우선.
    관계·사회진입 영역은 게이트(대인/외출 부담) 통과 시에만 배정.

(C) 오늘의 챌린지 3개 — LLM이 생성
- 분류기는 여기까지만 결정: [챌린지영역 + 난이도밴드(밴드-1 / 밴드 / 밴드+1) + 금지조건].
- 이 조건을 LLM에 넘기면, LLM이 같은 영역·난이도 낮음/중간/높음의 챌린지 3개를 생성한다(아래 "LLM 챌린지 생성").
- 컨디션=바닥이면 전체 밴드 -1. 관심사(취향)는 LLM이 챌린지 문구에 녹인다.

(D) 다음 날 조정 — 회고 입력 후(수락한 1개 기준)
- 완료 + 부담도😌(쉬움)  → 밴드 +1 (또는 다음 영역으로 확장: 1→2→3→4)
- 완료 + 부담도😐(적당)  → 밴드 유지
- 완료 + 부담도😣(버거움)→ 밴드 유지 또는 -1
- 미완료                  → 밴드 -1, 더 작은 단위로
- 미완료 2회 연속         → 최저 밴드 + 부담 낮은 영역 + 응원 메시지
※ 난이도 숫자는 사용자에게 노출하지 않는다. 챌린지이 바뀔 때는 "커튼 여는 게 익숙해졌죠?
   오늘은 조금 다른 걸 해볼까요?"처럼 '네가 자랐다'는 성장 프레이밍으로 보여준다.

## 챌린지 예시 뱅크 (LLM few-shot · 참고 예시 · 안전망)
아래는 정답이 아니라 LLM에 주는 톤·난이도 예시이자, LLM 호출 실패 시 즉시 대체용이다.
LLM은 이 예시를 그대로 쓰지 말고, 사용자 맥락(온보딩 정보·오늘 설문·관심사)을 반영해 변형·생성한다.
단, 이것은 예시에 불과하며, 각 영역의 챌린지 카테고리는 추후 '챌린지 카테고리 DB'로 제공 예정이다.

[① 생활리듬]
L1 오늘 일어난 시간 기록하기 (1분)
L2 커튼 열기 / 물 한 컵 마시기 (2분)
L3 기상 알람 하나 맞춰두기 (2분)
L4 아침 햇빛 5분 쬐기 (5분)
L5 3일 연속 기상 시간 기록하기 (진행형)

[② 신체·정서 건강(자기돌봄)]  ※ 산책 등 저강도 외출성 신체활동 포함
L1 지금 기분 이모지 하나 고르기 (1분)
L2 세수 또는 양치하기 (3분)   / (관심=음악) 좋아하는 음악 한 곡 듣기 (5분)
L3 오늘 감정 한 줄 기록하기 (2분) / (관심=책) 좋아하는 글 한 쪽 읽기 (5분)
L4 10분 스트레칭 또는 샤워하기 (10분) / (관심=식물) 창가 화분·식물 돌보기 (5분)
L5 집 근처 10분 산책하기 (10분)

[③ 관계]  ※ 반드시 대인접촉 부담 게이트 통과 시에만. 은둔 단계엔 L1까지만.
L1 가족·지인 메시지 하나 '읽음'만 하기 (1분)
L2 관심 커뮤니티 글 1개 읽어보기 (5분)
L3 관심 글에 이모지/댓글 하나 남기기 (3분)
L4 안부 문자 한 통 보내기 (5분)
L5 짧은 통화 한 번 걸어보기 (10분)

[④ 사회진입(경제·활동)]  ※ 목적지 외출·경제활동 게이트 통과 시.
L1 관심 직무/분야 하나 골라보기 (3분)
L2 관심 분야 정보 5분 탐색하기 (5분)
L3 이력서 한 줄(내 강점) 써보기 (10분) / 편의점·카페에서 직접 주문해보기 (15분)
L4 지역 청년지원 정보 하나 확인·저장하기 (10분)
L5 희망 회사·프로그램 1곳 조사 + 요건 정리하기 (20분)

## 회고 — 챌린지별 맥락 질문(완료 후 1개 노출)
- 산책/외출 계열: "걷는 동안 뭐가 제일 괜찮았어요?" (바람·공기 / 음악 들으며 / 구경하는 재미 / 그냥 움직인 것)
- 음악/콘텐츠 계열: "오늘 본·들은 건 어느 쪽이었어요?" (웃긴 것 / 잔잔한 것 / 배우는 것 / 몰입되는 것)
- 요리/먹기 계열: "다음에 또 한다면?" (같은 것 또 / 다른 것 도전 / 이건 그만)
- 그 외: 부담도·만족도 이모지 + 한 단어만.

## 보상(캐릭터) 규칙
- 챌린지 완료 → 포인트 +지급, 캐릭터에 챌린지 관련 요소 반영(예: 산책→운동화, 식물 돌봄→화분, 음악→헤드폰).
- 누적 완료·연속일에 따라 배경(방 안→방 밖→동네)이 조용히 확장.
- 타이틀 획득 시 새 꾸미기 카테고리 해금(뱃지), 포인트로 해금 카테고리 상점에서 구매.
- 반복 수행할수록 취향(관심사) 관련 요소가 캐릭터에 더 드러남.

## LLM 챌린지 생성 (오늘 구현 · 서비스의 핵심)
데이터 흐름: [사용자] → 분류기가 '챌린지 조건' 산출 → 그 조건 + 예시 + 사용자 맥락을 LLM에 전달
→ LLM이 오늘의 챌린지 3개 생성 → Replit 껍데기가 카드로 표시.

LLM에 넘기는 3가지 입력:
1) 챌린지 조건(분류기 출력): 회복단계, 챌린지영역, 난이도밴드(낮음/중간/높음), 금지조건
2) 예시(few-shot): 위 예시 뱅크에서 해당 영역·난이도 항목 몇 개
3) 사용자 맥락:
   - 온보딩 정보: 수면패턴, 외출부담, 대인접촉부담
   - 오늘 설문: 컨디션, 희망영역, 관심사(취향)

[system 프롬프트 — 가드레일]
당신은 고립 청년의 회복을 돕는 챌린지 설계자입니다. 아래 '챌린지 조건'과 '사용자 맥락'에 맞는
오늘의 챌린지 3개를 생성하세요(같은 영역, 난이도 낮음→중간→높음 순).
예시는 톤·난이도 참고용일 뿐이며, 그대로 쓰지 말고 사용자의 관심사와 오늘 상태를 반영해 개인화하세요.
반드시 준수:
- 챌린지영역과 난이도밴드를 벗어나지 않는다. 각 챌린지은 5~15분 내 끝나는 아주 작은 행동.
- 금지조건에 해당하는 행동(대면·전화·외출 등)은 절대 포함하지 않는다.
- 지시·명령·평가·비교·재촉 표현 금지("~해야 한다","왜 안 했나요","꼭·반드시·매일" 금지). 담백·따뜻하게.
- 관심사(취향)를 자연스럽게 녹인다(예: 관심=음악 → 음악과 엮은 챌린지).
- 추상적 조언("긍정적으로 생각하기") 금지. 구체적·실행가능하게.
