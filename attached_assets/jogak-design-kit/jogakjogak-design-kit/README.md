# 조각조각 디자인 킷

'조각조각' 앱의 **BA(행동활성화) 챌린지 사이클 디자인본과 설계 원칙**을 다른 프로젝트로 옮기기 위한 꾸러미입니다.

## 구성

| 경로 | 내용 |
|---|---|
| `design-principles.md` | 확정된 제품·디자인 원칙 (**필독**) |
| `design-tokens.json` | 컬러 팔레트, 라운드 값 등 디자인 토큰 |
| `screens/` | 화면 이미지 13장 — 6개 화면의 모든 단계·상태 (366px 폭) |
| `components/` | React + Tailwind 목업 소스 (6화면 + 공용 요소) |

## 사용법

1. 대상 Replit 프로젝트의 Agent 채팅에 이 zip을 **첨부**하세요.
2. 아래 프롬프트를 함께 붙여넣으세요. (React 프로젝트가 아니어도 동작합니다)

> 첨부한 zip은 '조각조각' 앱의 디자인 킷이야. 압축을 풀고 `design-principles.md`의 원칙과 `design-tokens.json`의 팔레트를 반드시 따라줘. `screens/` 이미지가 기준 화면이야. 이 프로젝트가 React + Tailwind라면 `components/` 소스를 이식해서 쓰고, 다른 스택이라면 이미지와 원칙 문서를 기준으로 동일한 화면을 구현해줘.

## components/ 사용 시 알아둘 것

- **React + Tailwind CSS 전제**입니다 (`rounded-[20px]` 같은 임의값 문법 사용).
- `_shared/Shared.tsx`의 `PhoneFrame`은 **미리보기용 폰 껍데기**입니다. 실제 앱에서는 각 화면의 내용물만 옮기고 PhoneFrame은 버리세요.
- 컴포넌트가 URL 쿼리(`?step=1` 등)로 초기 상태를 받는 부분은 **스크린샷 캡처용 장치**입니다. 그대로 둬도 무해하지만, 실제 앱에서는 상태 관리로 교체하세요.
- `_group.css`는 목업 프리뷰 전용 보조 스타일입니다. 필요할 때만 참고하세요.
