# 조각조각 — 설계 원칙 (BA 챌린지 사이클)

'조각조각'은 **은둔·고립 청년**을 위한 행동활성화(Behavioral Activation) 기반 챌린지 앱입니다.
대상 사용자 특성상, **판단·처벌·압박으로 읽힐 수 있는 모든 요소를 배제**하는 것이 디자인 전체의 대전제입니다.

> 이 문서의 규칙들은 2026-07 BA 사이클 개선 보고에서 팀이 확정한 사항입니다. 새 화면·기능을 만들 때 이 원칙과 충돌하면 원칙이 우선입니다.

---

## 1. 챌린지 사이클 구조

```
온보딩 스토리(설득) → 7일 시작 데이터 쌓기 → [매일 반복] 데일리 서베이
  → 조각(미션) 제안 → 수행 → 인증(또는 건너뜀 기록) → 마이페이지(기록 확인)
```

- "조각"은 아주 작은 단위의 행동 미션입니다. 사용자는 조각을 모아 퍼즐을 맞추듯 하루를 채웁니다.
- 추천 알고리즘의 입력: 기분 체크(5점), 오늘의 영역 선택, P/M 점수 이력, 건너뜀 신호, (주 1회) 관심사.

## 2. 프레이밍 가드레일 — 절대 규칙

1. **실패 프레이밍 금지.** 건너뛴 조각은 어디에서도 "실패"가 아닙니다. 건너뜀은 (명시적으로 기록된 경우에만) 회피 *신호*로 집계되어 다음 제안을 조정하는 데 쓰일 뿐, 사용자 잘못으로 표시하지 않습니다. 페널티·강등 어휘 금지 — 내부 로직에 난이도 하향이 있어도 사용자에게 "내려갔다"고 말하지 않습니다.
2. **스트릭을 핵심 루프로 쓰지 않기.** 스트릭 단절의 역효과는 연구로 확인된 사항입니다. 게임화 요소(수집, 마스코트의 다정함)는 보조 장치일 뿐 핵심 동기 장치가 아닙니다. 마이페이지의 "연속 참여"는 기록 표시이며, 끊겨도 아무 불이익·경고가 없어야 합니다.
3. **"기분이 아니라 계획대로" (Martell).** 사이클의 척추입니다. 앱은 미션 전에 "하고 싶은 기분인가요?"를 절대 묻지 않습니다. 기분 체크는 데이터 수집이지 수행 여부의 관문이 아닙니다.
4. **낙인 어휘 금지.** 앱 내 문구에 치료·증상·우울증 등 임상 어휘를 쓰지 않습니다. (내부 문서·보고서에서는 이론 인용 가능)

## 3. 입력·척도 규칙

| 항목 | 규칙 | 이유 |
|---|---|---|
| 즐거움(P)·뿌듯함(M) 슬라이더 | 0–10, **초기값 없음** — 터치 전에는 핸들·수치 미표시 | 기본값 앵커로 인한 무성의 응답이 밴드 계산을 오염시키는 것 방지 |
| 기분 체크 | **5점 척도** (7점·10점 아님) | 응답 부담 최소화 |
| 조각 난이도 | 기본값은 **낮게**("가볍게"부터 시작), 숙달 조건 충족 시에만 단계 상승 | 성공 확률 최대화 우선 (Lejuez BATD 위계 로직) |
| P/M 내부 처리 | 0–10 값을 내부적으로 5밴드로 매핑 (M→난이도 밴드, P→즐거움 풀) | 노이즈 완화 |

## 4. 화면별 설계 결정 (screens/ 이미지 대응)

### 온보딩 스토리 — `onboarding-story-1~4.jpg`
- 4단계 스토리로 BA 원리를 낙인 없이 설득: ① 공감(아무것도 하기 싫은 날) → ② 기분-회피 악순환 시각화 → ③ 순서 뒤집기(작은 행동이 먼저, 기분이 따라옴) → ④ 가치 찾기로 전환.
- 마스코트 표정이 단계 감정을 대신 표현. 건너뛰기 항상 제공(강요 없음).

### 7일 시작 데이터 쌓기 — `onboarding-week-1.jpg`
- 첫 주는 마찰이 거의 없는 초소형 고정 조각(물 한 잔, 창문 열기 등)으로 시작 데이터를 수집.
- 오늘 항목만 CTA 활성, 지난 항목은 완료 체크, 미래 항목은 흐리게. 마스코트가 누적 개수를 응원 톤으로 언급.

### 데일리 서베이 — `daily-survey-1~2.jpg`
- 기분(5점) + 오늘의 영역(수면/식사/규칙적 일상/잘 모르겠음) **둘 다 선택해야만** "조각 추천받기" CTA가 나타남.
- "잘 모르겠어요"도 정식 선택지 — 결정 부담을 앱이 대신 짊어짐("조각이가 골라드릴게요").
- 관심사 질문은 주 1회만, 건너뛰기 가능(선택 질문임을 명시).

### 조각 제안 — `mission-proposal-1~2.jpg`
- 4개 영역 카드: 생활 리듬 / 자기 돌봄 / 즐거움 / 작은 용기. 선택한 카드가 펼쳐지며 난이도·시간대·장소를 조정.
- 난이도 상승은 이유와 함께 제안: "'가볍게'를 이틀 연속 잘 해내서, 이번엔 '보통'부터 추천해요" — 시스템이 올려주는 것이지 사용자가 요구받는 게 아님.
- 계속 미뤄진 조각은 **더 작게 쪼개서** 재제안 (배지: "계속 미뤄왔던 조각, 더 작게 쪼갰어요") — 회피 신호의 유일한 표면화 방식.

### 조각 인증 — `reflection-1~3.jpg`
- P/M 슬라이더는 초기값 없음(§3). 입력 후 주간 요약은 따뜻한 문장으로("이번 주, 조각을 맞춘 날 기분이 평균 한 칸 높았어요").
- 메모·사진은 전부 선택 사항.
- 건너뜀은 별도 링크("혹시 조각을 건너뛰었나요?") 뒤에 배치, 첫 문장은 **"괜찮아요, 그럴 수 있어요."** 사유는 비난 없는 칩으로 수집(피곤함/잊음/시간 부족/다른 일/그냥 싫었음) — 다음 제안 조정에만 사용.

### 마이페이지 — `mypage-1.jpg`
- 핵심 그래프는 **기분×활동 상관**("움직인 날, 기분이 올라갔어요") — BA 원리를 사용자 자신의 데이터로 증명하는 화면.
- 모은 조각 수·영역별 분포 중심의 수집형 표현. 연속 참여는 기록일 뿐(§2-2).

### 형태·타이포·톤
- **라운드는 크게**: 카드 20–24px, 버튼은 완전 라운드(필 형태). 직각 모서리 없음.
- 그림자는 은은하게, 테두리는 1px 라이트 톤 — 눌리는 느낌보다 떠 있는 느낌.
- 마스코트(노란 원형 얼굴)가 감정 표현을 대신함 — 사용자를 평가하는 표정(실망 등)은 금지, 슬픔·공감·응원까지만.
- **문구 톤: 다정한 존댓말 + 권유형.** "~해볼까요?", "~해보세요"까지만. 명령·훈계·자책 유도("아쉽네요", "놓쳤어요") 금지.
- 이모지는 UI 텍스트에 최소한으로, 의미 전달용으로만.

## 6. 근거 소싱 규칙 (기획 문서 작성 시)

- 인용은 **피어리뷰 저널·표준 치료 매뉴얼만** 허용 (Lejuez BATD, Martell, Beck, JMIR/World Psychiatry 메타분석, Moodivate RCT 등).
- **석사·박사 학위논문은 근거로 사용 금지** (팀 확정 사항).
